# Security

The Cheatcode installer writes files into your AI apps, so we take reports seriously.

Report a vulnerability to **admin@cheatcodehq.com** with "Security" in the subject. Please do not open a public issue
for it. You will get a reply within three working days.

In scope: the installer in this repository, the install links it accepts (`cheatcode://install`, `cheatcode://mcp`),
and the package format. The hosted website and API at cheatcodehq.com are in scope too; please do not run load or
scanning tools against them.
