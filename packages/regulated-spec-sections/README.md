# Regulated Spec Sections

Two skills written by Cheatcode that put the regulatory thinking into a spec at the start instead of the end: fintech-spec-section maps which obligations a money-moving feature triggers and writes requirements with control owners, audit events and exception paths plus the questions for compliance and the partner bank; healthcare-spec-section determines whether a feature handles PHI, writes the safeguards, consent, analytics de-identification and clinical-influence assessment, and the questions for privacy, security and clinical reviewers. Both are review drafts for the relevant experts, not legal advice.
